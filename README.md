# страховая компания

## Описание предметной области

Организация представляет собой компанию по страхованию жизни и здоровья физических лиц. Деятельность компании охватывает полный цикл взаимодействия клиента с системой обслуживания — от первичной консультации и оформления страхового полиса до обработки страховых случаев и выплаты возмещения.

Клиент обращается за консультацией, указывает цели страхования (например, защита семьи, покрытие медицинских расходов). На основе его данных агент подбирает подходящий тип страхования, оформляет полис и передаёт его на утверждение. После заключения договора клиент может в случае наступления страхового события подать заявление. Система проверяет соответствие случая условиям полиса, проводит оценку ущерба (включая медицинскую экспертизу), рассчитывает и выплачивает возмещение. Все этапы фиксируются в системе, формируются документы (страховой случай, чек, уведомление), которые доступны клиенту в личном кабинете.
